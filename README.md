# 🐜 Sugar Ants — Медитативная колония

Мультиплатформенная (ПК + телефон / PWA) медитативная пиксельная игра на TypeScript + HTML5 Canvas + Web Audio API. Выпускайте колонию муравьёв, прогрызайте туннели в породе, открывайте скрытые светящиеся картины, эволюционируйте колонию и ищите заветный кусочек сахара!

## Режимы игры

- **Классический режим** — 5 уникальных карт со своей цветовой гаммой, скрытыми светящимися картинами и пасхалками, 4 типами породы с разной прочностью, пространственным древом навыков, 5 видами муравьёв (*Рабочий, Воин, Разведчик, Матка, Компас*) и системой постоянных **Мутаций** после каждого пройденного уровня.
- **Сюжетный режим («Забытая ферма»)** — уютный разрез стеклянной муравьиной фермы на подоконнике. Развивайте экономику колонии (*Пастухи тлей* для нектара, *Няньки личинок*, усиление жвал), прогрызайте пробку в крышке фермы и выбирайтесь на свободу к сахару.
- **Мультиплеер («Битва за Сахар»)** — ⚔ **Гонка 1 на 1** или 🤝 **Кооператив**:
  - Онлайн P2P по коду комнаты (`ANT-XXXX`) через WebRTC (PeerJS) — работает прямо на GitHub Pages без отдельного сервера!
  - Локальная игра в 2 вкладках браузера (`BroadcastChannel`).
  - Быстрый матч против **ИИ-колонии**.

## Саундтреки (Web Audio API)

8 встроенных процедурных саундтреков без внешних аудиофайлов:
- 3 трип-хоп трека (*Бристольский туман*, *Ночной винил*, *Бархатная тень* — в духе Portishead и Massive Attack)
- IDM-электроника (*Кремниевый сон* — в духе Aphex Twin)
- 4 медитативных эмбиент-трека (*Изумрудный шёпот*, *Лунная пыль*, *Глубокое гнездо*, *Звёздный путь*)
- Автоматическая смена саундтреков (можно отключить в Настройках).

## Управление

- **Тап / Клик** или **Потягивание** — выпустить муравья (потягивание задаёт точное направление стрелкой).
- **Колесо мыши / Щипок двумя пальцами** — масштаб (зум).
- **ПКМ / Два пальца** — перемещение камеры.
- **Клавиши `1`–`5`** — выбор типа муравья, **`R`** — центрировать камеру, **`Esc`** — меню.

## Локальный запуск

```bash
npm install
npm run dev
```
